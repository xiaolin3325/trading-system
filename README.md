# 🐻 小布交易系统

A股短线量化交易管理系统。记录持仓、观察池、交易复盘，实时行情自动计算盈亏。

## 功能

- **持仓管理** — 记录买入卖出，实时行情自动算盈亏
- **观察池** — 加入关注个股，带现价和涨跌幅
- **连板梯队** — 每日涨停连板数据
- **技术扫描** — BBI回踩低吸 / N字突破战法 自动选股
- **复盘分析** — 交易统计、已实现盈亏、交易流水

## 快速开始

```bash
# 安装依赖
pip install flask requests

# 启动
cd trading
python server.py

# 打开浏览器访问 http://localhost:18989
```

也可双击 `启动服务.bat` 一键启动。

## 命令（Telegram / CLI）

```
加入观察 <代码> [原因]
买入 <代码> <股数> <价格> [备注]
卖出 <代码> <股数>
持仓
观察池
交易记录
连板梯队
```

## 技术栈

- 后端: Python + Flask + SQLite
- 前端: 纯HTML / CSS / Vanilla JS
- 数据: 新浪财经实时行情API

## 策略

- **BBI回踩低吸** — 强势股回调到多空线附近企稳买入
- **N字突破** — 大阳线后缩量回调，二次放量启动时跟进
- **尾盘竞价捡漏** — 弱势行情尾盘异动套利
